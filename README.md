# آی‌حساب — iHesab

برنامه حسابداری فروشگاهی فارسی، کاملاً آفلاین — نسخه اندروید و ویندوز.

A Persian (Farsi) offline shop-accounting app — invoices, inventory, cheques, customers,
double-entry bookkeeping, Excel import/export, printable invoices, online catalog.
Android (WebView) + Windows (Electron) builds share the same web core in `www/`.

## امکانات

- 🧾 فاکتور فروش/خرید/برگشتی/پیش‌فاکتور + چاپ و PDF و اشتراک‌گذاری
- 📦 انبار و موجودی با بهای میانگین موزون، بارکد و اسکنر
- 👥 مشتریان و تأمین‌کنندگان، مانده و گردش حساب اشخاص
- 💳 چک‌ها (دریافتی/پرداختی) با یادآور سررسید، دریافت/پرداخت نقد و بانک و کارت‌به‌کارت
- 📒 حسابداری دوطرفه: دفتر روزنامه و کل، تراز آزمایشی، ترازنامه، سند دستی
- 🛍️ کاتالوگ آنلاین تک‌فایلی + ثبت خودکار سفارش واتساپ به‌صورت فاکتور
- 📊 گزارش‌ها، داشبورد، پشتیبان‌گیری و بازیابی، قفل برنامه و کاربران داخلی

## ساختار

- `www/` — هسته وب برنامه (HTML/CSS/JS)؛ در هر دو نسخه اندروید و ویندوز استفاده می‌شود
- `android/` — پوسته اندروید (WebView + پل جاوا)
- `build.sh` — بیلد دستی APK (aapt2/javac/d8/apksigner)

## ساخت نسخه اندروید

پیش‌نیاز: JDK 17 و Android SDK (build-tools 34). کی‌استور در این مخزن نیست؛ کی‌استور خودتان
را بسازید و رمزها را در `build.sh` جای `CHANGE_ME` بگذارید، بعد:

```bash
bash build.sh
```
